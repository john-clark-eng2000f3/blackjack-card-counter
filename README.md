# blackjack-card-counter

I play enough blackjack that mental counting started to slip after a few drinks. This is a small terminal tool I run between hands to track the count and remaining deck composition.

## install

pip install -r requirements.txt

## usage

python blackjack_counter.py --decks 6

If you want to reset mid-session, just Ctrl-C and restart.
